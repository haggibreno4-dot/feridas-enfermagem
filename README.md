# Feridas Enfermagem

Plataforma de estudos sobre avaliação e cuidado de feridas em enfermagem.

## Conteúdo
- Avaliação sistemática da ferida
- Leito e cicatrização
- Coberturas
- Prevenção
- Registro de enfermagem
- Quiz de revisão

## Rodar localmente
Execute npm start e acesse http://localhost:3000.

> Material educacional. Não substitui protocolos institucionais, diretrizes atualizadas ou avaliação clínica profissional.
